## Troubleshooting

| Issue | Solution |
|-------|----------|
| Login fails | Check seed ran: `npm run db:seed` |
| No data | Clear DB and reseed: `npx prisma db push --force-reset && npm run db:seed` |
| Slow loading | Check Redis connection, increase timeout |
| Notice not showing | Verify workspaceId matches tenant |
